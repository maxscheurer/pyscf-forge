$\dfrac{\partial^2 e_g}{\partial R_{Ax}\, \partial R_{By}}$ -- Full Derivation Reference

1. The integral and its dependencies

$$e_g = \sum_{ij} D_{ij}\; I_{ij,g}, \qquad I_{ij,g} = \big\langle \chi_i(\mathbf{r};\, \mathbf{R}_i) \,\big|\, e^{-\omega_g\,|\mathbf{r}-\mathbf{R}_g|^2} \,\big|\, \chi_j(\mathbf{r};\, \mathbf{R}_j) \big\rangle$$

$I_{ij,g}$ depends on geometry $\mathbf{R}$ through four channels:

ChannelVariableWhen it contributes to $d/dR_{Ax}$
Bra center$\mathbf{R}_i$$i \in A$ (basis function $i$ sits on atom $A$)
Ket center$\mathbf{R}_j$$j \in A$ (basis function $j$ sits on atom $A$)
Gaussian center$\mathbf{R}_g$$g \in A$ (grid point $g$ belongs to atom $A$)
Exponent$\omega_g = \frac{\pi \ln 2}{A_g(\mathbf{R})}$Always (areas depend on all atoms)

2. First derivative -- four parts

$$\frac{dI_{ij,g}}{dR_{Ax}} = \underbrace{\frac{\partial I_{ij,g}}{\partial R_{i,x}}\,\delta_{i\in A}}_{\text{bra}} + \underbrace{\frac{\partial I_{ij,g}}{\partial R_{j,x}}\,\delta_{j\in A}}_{\text{ket}} + \underbrace{\frac{\partial I_{ij,g}}{\partial R_{g,x}}\,\delta_{g\in A}}_{\text{center}} + \underbrace{\frac{\partial I_{ij,g}}{\partial \omega_g}\,\frac{d\omega_g}{dR_{Ax}}}_{\text{width}}$$

Tracing with D:

$$\frac{de_g}{dR_{Ax}} = \underbrace{\sum_{\substack{i\in A \\ j}} D_{ij}\,\frac{\partial I_{ij,g}}{\partial R_{i,x}}}_{\displaystyle T^{\text{bra}}_{Ax,g}} + \underbrace{\sum_{\substack{i \\ j\in A}} D_{ij}\,\frac{\partial I_{ij,g}}{\partial R_{j,x}}}_{\displaystyle T^{\text{ket}}_{Ax,g}} + \underbrace{\delta_{g\in A}\sum_{ij} D_{ij}\,\frac{\partial I_{ij,g}}{\partial R_{g,x}}}_{\displaystyle T^{\text{cen}}_{Ax,g}} + \underbrace{\frac{d\omega_g}{dR_{Ax}}\sum_{ij} D_{ij}\,\frac{\partial I_{ij,g}}{\partial \omega_g}}_{\displaystyle T^{\omega}_{Ax,g}}$$

Validated: $\frac{de_g}{dR_{Ax}} = T^{\text{bra}} + T^{\text{ket}} + T^{\text{cen}} + T^{\omega}$ matches fdiff to $3\times 10^{-10}$.

Explicit forms

In PySCF, int3c1e_ip1 computes $-\partial I/\partial R_{\text{bra}}$. So:

$$T^{\text{bra}}_{Ax,g} = -\sum_{i\in A,\, j} D_{ij}\;\texttt{ip1}_{x,i,j,g}$$ $$T^{\text{ket}}_{Ax,g} = -\sum_{i,\, j\in A} D_{ij}\;\texttt{ip1}_{x,j,i,g} \quad\text{(by integral symmetry } I_{ij}=I_{ji}\text{)}$$ $$T^{\text{cen}}_{Ax,g} = -\delta_{g\in A}\sum_{ij} D_{ij}\;\texttt{ip1\_aux}_{x,g,i,j}$$ $$T^{\omega}_{Ax,g} = w_g\,\frac{\partial A_g}{\partial R_{Ax}}\cdot(-\text{diagd\_dm}_g)$$

where $w_g = -\pi\ln 2/A_g^2$ and $\text{diagd\_dm}_g = \sum_{ij}D_{ij}\langle i||\mathbf{r}-\mathbf{R}_g|^2 e^{-\omega_g|\mathbf{r}-\mathbf{R}_g|^2}|j\rangle$.

3. Second derivative -- differentiate each of the four parts

We need:

$$\frac{\partial^2 e_g}{\partial R_{Ax}\,\partial R_{By}} = \frac{\partial}{\partial R_{By}}\Big[ T^{\text{bra}}_{Ax,g} + T^{\text{ket}}_{Ax,g} + T^{\text{cen}}_{Ax,g} + T^{\omega}_{Ax,g} \Big]$$

Each of the four terms depends on $R_{By}$ through positions AND through $\omega_g$:

3a. $\dfrac{\partial}{\partial R_{By}} T^{\text{bra}}_{Ax,g}$

$T^{\text{bra}}_{Ax,g} = \sum_{i\in A,j} D_{ij}\,\frac{\partial I_{ij,g}}{\partial R_{i,x}}$. The quantity $\frac{\partial I}{\partial R_{i,x}}$ depends on $R_{By}$ through:

  • $R_j$ moves (if $j\in B$): gives $\frac{\partial^2 I}{\partial R_{i,x}\,\partial R_{j,y}}$ -- ipvip1
  • $R_i$ moves (if $i\in B$, so $A=B$): gives $\frac{\partial^2 I}{\partial R_{i,x}\,\partial R_{i,y}}$ -- ipip1
  • $R_g$ moves (if $g\in B$): gives $\frac{\partial^2 I}{\partial R_{i,x}\,\partial R_{g,y}}$ -- ip1ip2
  • $\omega_g$ changes: gives $\frac{\partial^2 I}{\partial R_{i,x}\,\partial\omega_g}\cdot\frac{d\omega_g}{dR_{By}}$ -- cross (bra x $\omega$)

3b. $\dfrac{\partial}{\partial R_{By}} T^{\text{ket}}_{Ax,g}$

Same structure as 3a with bra/ket swapped (by integral symmetry $I_{ij}=I_{ji}$).

3c. $\dfrac{\partial}{\partial R_{By}} T^{\text{cen}}_{Ax,g}$

$T^{\text{cen}}_{Ax,g} = \delta_{g\in A}\sum_{ij} D_{ij}\,\frac{\partial I_{ij,g}}{\partial R_{g,x}}$. The quantity $\frac{\partial I}{\partial R_{g,x}}$ depends on $R_{By}$ through:

  • $R_i$ moves (if $i\in B$): gives $\frac{\partial^2 I}{\partial R_{g,x}\,\partial R_{i,y}}$ -- ip1ip2 (transposed)
  • $R_j$ moves (if $j\in B$): same by symmetry
  • $R_g$ moves (if $g\in B$, so $A=B$): gives $\frac{\partial^2 I}{\partial R_{g,x}\,\partial R_{g,y}}$ -- ipip2
  • $\omega_g$ changes: gives $\frac{\partial^2 I}{\partial R_{g,x}\,\partial\omega_g}\cdot\frac{d\omega_g}{dR_{By}}$ -- cross (center x $\omega$)

3d. $\dfrac{\partial}{\partial R_{By}} T^{\omega}_{Ax,g}$

$T^{\omega}_{Ax,g} = \frac{d\omega_g}{dR_{Ax}}\cdot\sum_{ij}D_{ij}\frac{\partial I_{ij,g}}{\partial\omega_g}$. Product rule:

$$\frac{\partial T^{\omega}_{Ax,g}}{\partial R_{By}} = \frac{d^2\omega_g}{dR_{Ax}\,dR_{By}}\cdot\sum_{ij}D_{ij}\frac{\partial I}{\partial\omega_g} \;+\; \frac{d\omega_g}{dR_{Ax}}\cdot\frac{\partial}{\partial R_{By}}\!\left[\sum_{ij}D_{ij}\frac{\partial I}{\partial\omega_g}\right]$$

The second factor: $\sum_{ij}D_{ij}\frac{\partial I}{\partial\omega_g} = -\text{diagd\_dm}_g$, and its $R_{By}$-derivative has parts:

  • $R_i$ moves (if $i\in B$): position derivative of diagd -- cross ($\omega$ x bra)
  • $R_j$ moves (if $j\in B$): position derivative of diagd -- cross ($\omega$ x ket)
  • $R_g$ moves (if $g\in B$): position derivative of diagd -- cross ($\omega$ x center)
  • $\omega_g$ changes: gives $\frac{d\omega_g}{dR_{By}}\cdot\sum_{ij}D_{ij}\frac{\partial^2 I}{\partial\omega_g^2}$ -- $\omega$ x $\omega$

4. Collected terms by integral type

Position x Position (from 3a, 3b, 3c -- all at fixed $\omega$)

$$\text{ipip1:}\quad \sum_{i\in A\cap B,\,j} (D_{ij}+D_{ji})\,\frac{\partial^2 I}{\partial R_{i,x}\,\partial R_{i,y}}$$ $$\text{ipvip1:}\quad \sum_{i\in A,\,j\in B} D_{ij}\,\frac{\partial^2 I}{\partial R_{i,x}\,\partial R_{j,y}} + (i\leftrightarrow j)$$ $$\text{ip1ip2:}\quad \delta_{g\in B}\sum_{i\in A,\,j}(D_{ij}+D_{ji})\,\frac{\partial^2 I}{\partial R_{i,x}\,\partial R_{g,y}} + (A\leftrightarrow B,\, x\leftrightarrow y)$$ $$\text{ipip2:}\quad \delta_{g\in A}\delta_{g\in B}\sum_{ij}D_{ij}\,\frac{\partial^2 I}{\partial R_{g,x}\,\partial R_{g,y}}$$

Position x Width crosses (from 3a/3b/3c $\omega$-part + 3d position-part)

$$\frac{d\omega_g}{dR_{By}}\;\mathrm{Tr}\!\left[\mathbf{D}\,\frac{\partial^2 I_g}{\partial R_{Ax}\big|_\omega\,\partial\omega_g}\right] \;+\; \frac{d\omega_g}{dR_{Ax}}\;\mathrm{Tr}\!\left[\mathbf{D}\,\frac{\partial^2 I_g}{\partial R_{By}\big|_\omega\,\partial\omega_g}\right]$$

where $\frac{\partial^2 I}{\partial R_{Ax}|_\omega\,\partial\omega_g}$ collects bra($i\in A$) + ket($j\in A$) + center($g\in A$) derivatives of $\partial I/\partial\omega = -\text{diagd}$.

Width x Width (from 3d)

$$\frac{d^2\omega_g}{dR_{Ax}\,dR_{By}}\;(-\text{diagd\_dm}_g) \;+\; \frac{d\omega_g}{dR_{Ax}}\,\frac{d\omega_g}{dR_{By}}\;(\text{gtype\_dm}_g)$$
